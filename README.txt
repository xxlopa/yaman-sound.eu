FREE DOWNLOAD WORKFLOW
----------------------
For every Sound / Release post in Pages CMS:
1. Fill in SoundCloud URL.
2. Open the same track/release on SoundCloud.
3. Copy the FREE DOWNLOAD link from its SoundCloud description.
4. Paste it into "Free Download URL".
5. If the field is empty, the FREE DOWNLOAD button is hidden automatically.
