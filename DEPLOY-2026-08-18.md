# YAMAN deploy — Newsletter update

This package is ready for GitHub Pages / Pages CMS.

## Included
- YAMAN newsletter 3:4 poster in `assets/uploads/newsletter/`
- Newsletter poster card on Events page
- Dedicated `/newsletter.html` with embedded Brevo signup
- Brevo public form action stored in `_data/site.yml`
- Newsletter poster/headline/CZ+EN text/Brevo action editable in Pages CMS → Site settings
- All newsletter CTA buttons stay on `yamansound.eu`
- Custom domain remains `yamansound.eu`

## Deploy
Replace the contents of the current GitHub Pages repository with the contents of this folder (keep the repository itself). Commit/push to the publishing branch. GitHub Pages will rebuild automatically.

After deploy, test `/newsletter.html` with an email address and confirm the new contact appears in Brevo.
